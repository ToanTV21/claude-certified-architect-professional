> Course 1 / 5 · [Skilljar](https://anthropic-partners.skilljar.com/path/claude-certified-architect-professional/claude-platform-solution-design)

**About:** Designing solutions with Claude goes beyond choosing a model. Four decisions come before
you build: what work Claude owns, what form it takes, which reference architecture to commit to,
and which model and context strategy keep the solution accurate and affordable.
